## Filmstrip Edition (v2.4.1-filmstrip-1.0.0)
**Based on:** JustCarmen Fancy Imagebar v2.4.1

This version includes specific UI enhancements to create a vintage "Filmstrip" look for your genealogy photos. See [Our Family Connections](https://genes.tronsmit.com) as an example.

### Key Features
* **Filmstrip Layout:** Introduces a 5px margin between images to mimic the spacing of a film strip.
* **Smart Scrolling:** Activates horizontal scrolling/swiping for image bars that are wider than the screen.
* **Sepia Styling:** Automatically applies a sepia tone to newly generated thumbnails.
    * *Note on Caching: This module shares the server-side image cache with standard versions of Fancy Imagebar. Existing cached thumbnails will remain in color until the module cache is cleared or the images are regenerated.*
